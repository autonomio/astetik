# Code of conduct

Astetik contributors keep communication factual, specific, and respectful. Harassment, threats, discriminatory language, personal attacks, deliberate disruption, and publishing private information are unacceptable.

Maintainers may remove comments, close issues, block participants, or use GitHub moderation when conduct prevents productive work. Enforcement should identify the behavior and proportionate response rather than making personal judgments.

For a private conduct report, use the existing contact for the [maintainer](MAINTAINERS.md). No independent conduct office or dedicated reporting service is established here.
