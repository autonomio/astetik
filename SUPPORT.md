# Support

Use [repository issues](https://github.com/autonomio/astetik/issues) for reproducible bugs, usage questions, and feature requests. Suspected vulnerabilities follow [SECURITY.md](SECURITY.md); conduct concerns follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Useful evidence

Include the Astetik version or source commit, Python version, operating system, exact command or declaration, minimal reproduction using shareable actual data, and full relevant error output.
For scientific figures, include the specification, manifest, receipt identifier, and the expected versus observed computation or layout. Redact private observations and credentials before sharing.

Use [the documentation hub](docs/README.md) for workflows and [the catalogue](docs/Reference/Plot-Catalogue.md) for declared kinds. No support response time or hosted support service is promised.
